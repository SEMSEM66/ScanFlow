## 3. Made for Kids Declaration
- ScanFlow is categorized as a **Business / Productivity / Utilities** application.
- It does **not** opt into the "Made for Kids" dedicated App Store category because it is a professional productivity tool intended primarily for adults, students, and businesses managing personal and financial documents.
